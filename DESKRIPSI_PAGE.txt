1. LANDING PAGE (Halaman Utama)
================================================================================

Route: / (GET)
Controller: LandingController@index
View: resources/views/landing.blade.php

DESKRIPSI:
Landing page merupakan halaman pertama yang dilihat pengunjung ketika mengakses
aplikasi. Halaman ini dirancang dengan desain modern dan menarik menggunakan 
mesh gradient background dan animasi blob shapes yang dinamis.

FITUR UTAMA:
- Hero Section dengan background animasi gradient dan blob shapes
- Navbar transparan yang berubah menjadi solid saat di-scroll
- Informasi singkat tentang berpikir komputasional
- Call-to-action buttons untuk login dan register
- Penjelasan 4 pilar berpikir komputasional:
  * Dekomposisi (🧩) - Memecah masalah kompleks
  * Pengenalan Pola (🔍) - Mengidentifikasi pola dan kesamaan
  * Abstraksi (💡) - Fokus pada informasi penting
  * Algoritma (📝) - Membuat langkah-langkah sistematis
- Section fitur dengan cards untuk:
  * Materi Interaktif (teks dan video)
  * Quiz & Evaluasi dengan sistem level
  * Tracking Progress dengan grafik performa
- Section "Mengapa Berpikir Komputasional?" dengan penjelasan manfaat
- Footer dengan link navigasi dan copyright

DESAIN:
- Modern dan clean dengan Tailwind CSS
- Animasi fade-in-up untuk elemen-elemen
- Card hover effects dengan shadow dan transform
- Gradient backgrounds (indigo, purple, pink, teal)
- Responsive untuk mobile, tablet, dan desktop

TARGET PENGGUNA:
- Pengunjung umum (guest)
- Calon pengguna yang ingin mendaftar

6. EVALUASI (Halaman Quiz & Ujian)
================================================================================

Route: /evaluasi (GET)
Controller: EvaluasiController@index
View: resources/views/evaluasi/index.blade.php
Layout: x-learning-layout
Middleware: auth, verified

DESKRIPSI:
Halaman evaluasi memungkinkan siswa untuk mengerjakan quiz dan menguji
pemahaman mereka terhadap materi berpikir komputasional dengan sistem level.

FITUR UTAMA:
- Page Hero dengan deskripsi evaluasi
- Grid cards untuk 4 pilar quiz:
  * Dekomposisi (🧩 - Indigo)
  * Pengenalan Pola (🔍 - Teal)
  * Abstraksi (💡 - Amber)
  * Algoritma (📝 - Rose)
- Setiap card menampilkan:
  * Gradient header dengan emoji icon
  * Nama dan deskripsi pilar
  * Info: "24 Soal (8 × 3 Level)" dan "3 Level"
  * Best score dengan badge warna:
    - Hijau: score > 70 (Kuasai)
    - Amber: score 1-70 (Cukup)
    - Abu-abu: belum dikerjakan
  * Button "Mulai Quiz" atau "Lanjutkan Quiz"
- Info Banner dengan link ke halaman Performa

SISTEM LEVEL:
- Setiap pilar memiliki 3 level kesulitan:
  * Level 1: Mudah (8 soal)
  * Level 2: Sedang (8 soal)
  * Level 3: Sulit (8 soal)
- Level harus diselesaikan secara berurutan
- Unlock level berikutnya dengan score minimal

SUBPAGES:

6.1. LEVEL SELECTION PAGE
Route: /evaluasi/{pillar}/levels (GET)
Controller: QuizLevelController@selectLevel
View: resources/views/evaluasi/levels.blade.php

- Pilih level yang ingin dikerjakan
- Tampilkan status setiap level:
  * Locked (belum bisa diakses)
  * Available (bisa dikerjakan)
  * Completed (sudah selesai dengan score)
- Info jumlah soal dan durasi
- History attempts per level

6.2. START QUIZ PAGE
Route: /evaluasi/{pillar}/level/{level}/start (GET)
Controller: QuizLevelController@startLevel

- Instructions sebelum mulai quiz
- Informasi rules dan ketentuan
- Button "Mulai Quiz" untuk start attempt
- Create quiz_attempts record di database

6.3. QUIZ PAGE (Active Quiz)
Route: /evaluasi/{pillar}/level/{level}/quiz/{attempt} (GET)
Controller: QuizLevelController@showQuiz
View: resources/views/evaluasi/quiz-level.blade.php

FITUR:
- Header dengan info pilar dan level
- Progress indicator (soal ke-X dari Y)
- Timer countdown (optional)
- Question display area:
  * Nomor soal
  * Pertanyaan lengkap dengan gambar (jika ada)
  * Opsi jawaban (A, B, C, D)
  * Radio buttons untuk pilih jawaban
- Navigation buttons:
  * Previous Question
  * Next Question
  * Submit (di soal terakhir)
- Sidebar dengan thumbnail semua soal:
  * Menampilkan status: dijawab/belum
  * Quick navigation ke soal tertentu

SUBMIT ANSWER:
Route: /evaluasi/{pillar}/level/{level}/quiz/{attempt}/answer (POST)
Controller: QuizLevelController@submitAnswer

- AJAX submit untuk setiap jawaban
- Simpan ke quiz_answers table
- Real-time feedback (optional)
- No page reload

6.4. RESULTS PAGE
Route: /evaluasi/{pillar}/level/{level}/results/{attempt} (GET)
Controller: QuizLevelController@results
View: resources/views/evaluasi/results.blade.php

FITUR:
- Score summary dengan animasi:
  * Total score (percentage)
  * Jumlah benar dan salah
  * Waktu pengerjaan
  * Badge performance (Excellent/Good/Need Improvement)
- Breakdown per soal:
  * Nomor soal
  * Jawaban user
  * Jawaban yang benar
  * Pembahasan (explanation)
  * Indicator: ✓ benar atau ✗ salah
- Recommendations:
  * Link ke materi terkait jika score < 70
  * Button "Coba Lagi" atau "Lanjut ke Level Berikutnya"
  * Button "Lihat Performa Detail"

6.5. REVIEW PAGE (Old System)
Route: /evaluasi/{pillar}/review/{attempt} (GET)
Controller: EvaluasiController@review
View: resources/views/evaluasi/review.blade.php

- Review jawaban quiz yang sudah dikerjakan
- Mirip dengan results page tapi untuk attempt lama

DESAIN:
- Color-coded per pilar untuk konsistensi
- Progress bars dan indicators yang jelas
- Cards dengan shadow dan hover effects
- Gradient backgrounds
- Responsive untuk semua devices

DATABASE TRACKING:
- quiz_attempts: record setiap attempt
  * user_id, quiz_id, level, status, score
  * started_at, completed_at
- quiz_answers: jawaban per soal
  * attempt_id, question_id, selected_options
  * is_correct

7. PERFORMA (Halaman Analisis Progress)
================================================================================

Route: /performa (GET)
Controller: PerformaController@index
View: resources/views/performa/index.blade.php
Layout: x-learning-layout
Middleware: auth, verified

DESKRIPSI:
Halaman performa menampilkan analisis mendalam tentang progress belajar siswa
dengan visualisasi grafik, statistik, dan rekomendasi pembelajaran.

FITUR UTAMA:

7.1. STATS OVERVIEW (4 Cards di atas)
- Total Quiz Dikerjakan (Indigo)
  * Icon: checklist
  * Menghitung semua quiz_attempts yang completed
- Rata-rata Nilai (Teal)
  * Icon: chart arrow up
  * Average dari semua scores
  * Dalam bentuk percentage
- Pilar Dikuasai (Amber)
  * Icon: badge check
  * Jumlah pilar dengan best_score ≥ 70
  * Format: X/4 pillars
- Tingkat Penyelesaian (Rose)
  * Icon: star
  * Percentage completion dari semua materials
  * Calculated dari progress

7.2. GRAFIK PROGRES PER PILAR (Chart.js)
- Bar chart atau radar chart
- Sumbu X: 4 pilar (Dekomposisi, Pola, Abstraksi, Algoritma)
- Sumbu Y: Score (0-100)
- Data series:
  * Best Score per pilar (warna primer)
  * Average Score per pilar (warna sekunder)
  * Target Score 70% (garis putus-putus)
- Interactive tooltips
- Responsive dan animasi smooth

7.3. DETAIL PER PILAR (Cards)
- 4 cards dengan color-coded borders:
  * Dekomposisi (border-l-indigo-500)
  * Pengenalan Pola (border-l-teal-500)
  * Abstraksi (border-l-amber-500)
  * Algoritma (border-l-rose-500)
- Setiap card menampilkan:
  * Emoji icon + nama pilar
  * Best score dengan font besar
  * Progress bar dengan gradient
  * Mastery level:
    - "Kuasai" (hijau) jika score > 70
    - "Cukup" (amber) jika score 50-70
    - "Perlu Belajar Lagi" (merah) jika score < 50
    - "Belum Dikerjakan" (abu) jika 0
  * Total attempts untuk pilar tersebut
  * Last attempt date

7.4. RECOMMENDATIONS SECTION
- Conditional recommendations berdasarkan performance:
  * Jika ada pilar dengan score < 70:
    → Tampilkan card dengan icon warning
    → Saran: "Ulangi materi [nama pilar]"
    → Button link ke materi terkait
  * Jika semua pilar sudah > 70:
    → Tampilkan congratulations card
    → Icon trophy/medal
    → Motivasi untuk maintain performance
- Personalized study plan suggestions

7.5. HISTORY TABLE
- Tabel riwayat quiz attempts:
  * Tanggal (newest first)
  * Pilar + Level
  * Score dengan badge warna
  * Duration (waktu pengerjaan)
  * Action: Button "Lihat Detail" atau "Review"
- Pagination untuk banyak data
- Filter by pilar or date range
- Export to PDF/Excel (optional)

7.6. ACHIEVEMENT BADGES
- Badge system untuk motivasi:
  * "First Quiz" - quiz pertama selesai
  * "Perfect Score" - score 100%
  * "Consistent Learner" - 5 quiz berturut-turut
  * "Master" - semua pilar score > 80
- Display badges yang sudah didapat
- Locked badges yang belum tercapai

VISUALISASI DATA:
- Chart.js untuk grafik interaktif
- Progress bars dengan animasi
- Color-coded indicators
- Responsive tables

INSIGHTS GENERATED:
- Trend analysis (improving/declining)
- Weak areas identification
- Study recommendations
- Time spent tracking

DESAIN:
- Grid layout untuk stats cards
- Large chart area untuk visibility
- Detailed cards dengan clear typography
- Color system konsisten dengan pilar
- Print-friendly styling

TARGET INSIGHT:
- Membantu siswa identify weak areas
- Tracking progress over time
- Motivation through visualization
- Actionable recommendations
